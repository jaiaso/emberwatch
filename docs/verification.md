# v1.5.2 検証結果

Windowsの書き出し版を、RTX 4060 Ti、1152×720、Vulkan・高画質設定、垂直同期なしで測定。砦の周囲に味方48体と敵48体を追加した同じ戦場を固定し、描画をならした後の120フレームを比較しました。

| 指標 | v1.5.1 | v1.5.2 |
| --- | ---: | ---: |
| 平均フレーム時間 | 22.34 ms | 11.52 ms |
| フレーム時間の95パーセンタイル | 23.31 ms | 12.37 ms |
| 1フレームの描画命令 | 15,592 | 1,584 |
| 描画バッファ使用量 | 346.53 MiB | 33.96 MiB |
| 1フレームの描画ポリゴン数（影の描画を含む） | 21,673,007 | 21,673,007 |

- 同じ場面を撮影し、モデル、材質、影、画面効果を比較。画質設定と解像度をそろえて確認しました。
- 両版で戦闘を250ステップ進める試験を各5回実施。実行時刻で決まる試合IDを除いた状態のハッシュは全試行で一致。処理時間の中央値は3.19秒から3.04秒。
- 地形とスキル235項目、遠征284項目、英雄157項目、UI33項目が成功。v1.5.1とv1.5.2を混ぜた4プロセスで英雄選択、成長、復活、再戦を確認しました。
