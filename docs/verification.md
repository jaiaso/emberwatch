# 動作確認結果

Godot 4.5.1 / Windows x64で検証しています。

| 対象 | 結果 |
| --- | --- |
| シミュレーション | 32 / 32 項目成功 |
| 画面・操作 | 12 / 12 項目成功 |
| 協力プレイ | ホスト1＋参加者3の実プロセスで成功 |
| 敵80体がいる状態の同期 | 4人接続で成功 |
| 他人の部隊を操作する不正な指示 | ホスト側で拒否 |
| 圧縮データの順序逆転・欠落・古い状態・過大な分割片 | 復元または無視が仕様どおり |
| Windows実行版 | エクスポート後のEXEを起動し、画面を取得 |

ルールの検証には、採集による資源増加と枯渇、建築費の支払い、村人による完成と人口枠の増加、施設からの生産、修復、味方の操作権、離脱時の部隊移譲、塔・近接戦闘、襲撃数の人数補正、勝利・敗北を含みます。

操作の検証は実際の入力イベントを使い、タイトルボタンからの開始、V/F選択、建築と取消、進軍攻撃、説明画面、消音、生産を確認しています。

描画はOpenGL 3.3 / NVIDIA GeForce RTX 4060 Tiで確認しました。プレビュー画像は製品と同じ描画処理を使う、再現可能な展示用配置です。通常プレイは村人3人・剣士2人・弓兵1人から始まります。

通信検証は同じPCのループバック接続です。別PCのLAN接続、インターネット経由、遅延やパケット欠落を伴うネットワーク環境での実機検証は未実施です。ゲームバランスは試作段階です。
