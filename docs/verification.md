# v1.0.0 動作確認結果

Godot 4.5.1 / Windows x64で検証しています。

| 対象 | 結果 |
| --- | --- |
| シミュレーション | 53 / 53 項目成功 |
| 画面・操作 | 20 / 20 項目成功 |
| セーブ・再開・破損検出 | 8 / 8 項目成功 |
| 協力プレイ | ホスト1＋参加者3の実プロセスで成功 |
| 敵93体がいる状態の同期 | 4人接続で成功 |
| 戦闘中の途中参加 | 進行中の砦耐久と試合の状態を受信 |
| 部屋を維持した再戦 | 既存クライアントが新しい試合へ移行 |
| 途中離脱 | 残ったホストへ部隊と予約の指揮を移譲 |
| 標準難易度の通し検証 | 通常の採集・建築・生産指示で6波を防衛し、94体を撃破して勝利 |
| Windows実行版 | エクスポートしたEXEの起動と描画を確認 |

ルールの検証には、採集と枯渇、工事と人口枠、生産予約と取消返金、予約分を含めた人口制限、武器強化の実ダメージ、建物強化の既存・新築への適用、A*による中央砦の迂回、難易度による敵耐久、最終指揮官、勝敗を含みます。

通信はホストが操作権を検証し、分割された状態データの順序逆転・欠落・古い試合の混入を検証しています。セーブは時間・資源・部隊・生産予約・固有ID・乱数状態を保存し、改変や破損したデータを拒否します。

操作の検証は実際の入力イベントを使い、タイトルからの開始、部隊選択、建築と取消、進軍、タブ切替、部隊グループ、集合地点、一時停止、生産予約を確認しています。

描画はOpenGL 3.3 / NVIDIA GeForce RTX 4060 Tiで確認しました。プレビュー画像は同じ描画処理を使う展示用配置で、通常プレイは村人3人・剣士2人・弓兵1人から始まります。

通信の実プロセス検証は同じPCのループバック接続です。別PCのLAN接続、インターネット越し、実際に遅延や欠落がある回線での検証は未実施です。通し検証は基本的な自動操作による1条件で、長期のバランステストを保証するものではありません。
